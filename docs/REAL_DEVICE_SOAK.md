# Win2HomePod 実機検証の追加結果（2026-10-18）

対象はPR #4の実装コミット `da16418f0c1bb9a4f0ae07e8c63cacfbf9b4e1ae`。
Windows上のローカル検証ハーネスから、アプリ本体のAudioSessionとWASAPI取得を使った。
通常アプリの配置・設定は変更せず、専用の一時設定とログを使った。

## 確認できたこと

- 150 msのWASAPI経路では、合成音をHomePodからSoloCastまで届け、10回のチャープ音すべてを検出できた。
- 150 msの時刻差の中央値は約440 ms（439.6〜440.0 ms）。これは未校正の予備値。
- 同じ音・音量の40 msでは、送信前の音を10回検出したが、マイク側の一致は0回。遅延の値は出せない。
- 40 msの5分送信では取得・送信カウンターは継続したが、聴取者から無音との回答。出音の安定性合格には含めない。
- 合成の左右テストで40 ms設定が鳴った以前の結果は、WASAPI取得経路の出音を証明しない。

## 40 ms / 5分のWASAPI送信

合成音をCABLE Inputへ直接再生し、アプリでWASAPIループバック取得してALAC/PTPで2台へ送信。
Windowsの既定出力は切り替えない。

| 項目 | 結果 |
| --- | --- |
| 連続時間 | 300.1秒 |
| 送信数 | 2台とも37,608パケット |
| 切断 / 送信エラー / 再送要求 | 0 / 0 / 0 |
| 3秒の起動直後を除いた取得drop / 無音補充 | 0 / 0フレーム |
| 取得キュー最大 | 26.53 ms |
| 最大コールバック間隔 | 13.02 ms |
| Windows出力ロール | 不変 |
| 聴取 | 音が聞こえないとの回答。出音は不合格 |

確認音の振幅は0.25で、仮想出力の音量は約24%。メーターのピークは0.0604だった。
後の測定では振幅を0.9へ増やしたが、40 msのマイク一致は得られなかった。
無音の原因を音量だけとは断定しない。

## マイクによる予備測定

本人の許可を受けてSoloCastを15秒ずつ2回だけ取得した。音声ファイルは作らず、波形はメモリー内で処理して破棄。
送信前の専用仮想出力のループバックとマイクを48 kHzで取得し、WASAPIのQPC時刻で揃えた。
40 msのチャープ波形の正規化相互相関で対応を検出した。
事前に既知123 msの合成データを使い、遅延検出と雑音だけの誤検出排除を確認した。

| 項目 | 150 ms設定 | 40 ms設定 |
| --- | --- | --- |
| 送信前のチャープ | 10回 | 10回 |
| マイクで対応したチャープ | 10回 | 0回 |
| 時刻差の中央値 | 約440 ms | 算出不可 |
| 観測範囲 | 439.6〜440.0 ms | 該当なし |
| マイク最大振幅 | 0.297 | 0.0141 |
| 取得タイムスタンプエラー / 不連続 | 両方0 / 0 | 両方0 / 0 |

約440 msは「専用仮想出力のデジタル音から、HomePodを経てマイクに届く音まで」の時刻差の予備値。
WASAPI取得、送信、ネットワーク、受信機、空間伝搬とマイク経路を含む。
VB-CABLEとマイクのドライバー時刻の固定誤差を実機校正していないため、厳密なゲーム操作からの総遅延とは扱わない。
2台を同時に鳴らしているため主に拾えた音経路の値であり、左右の音響的な同期誤差は測っていない。
40 msの値は欠測なので、150 msとの差や改善量を計算しない。

WASAPI時刻の単位・意味は[MicrosoftのGetBuffer仕様](https://learn.microsoft.com/en-us/windows/win32/api/audioclient/nf-audioclient-iaudiocaptureclient-getbuffer)に基づく。

## 150 ms / 5分のWASAPI送信

確認音の振幅を0.9にし、同じ経路で再試験。開始後の聴取で5秒おきの音が聞こえるとの回答を得た。
5分を完了し、聴取者から「聞いていた範囲では音切れ・異音なし」との回答を得た。

| 項目 | 結果 |
| --- | --- |
| 連続時間 | 300.0秒 |
| 受信機1 / 2の送信数 | 37,600 / 37,598パケット |
| 切断 / 送信エラー / 再送要求 | 0 / 0 / 0 |
| 3秒の起動直後を除いた取得drop | 0フレーム |
| 同期間の無音補充 | 7フレーム、約0.16 ms相当 |
| 取得キュー最大 | 28.46 ms |
| 最大コールバック間隔 | 20.71 ms |
| メーターのピーク | 0.217 |
| 取得例外 | なし |
| Windows出力ロール | 不変 |
| 聴取 | 確認した範囲で音切れ・異音なし |

終了後に、元設定・復元記録のハッシュ不変、検証プロセスとPTP待受けが残らないことを確認した。
マイクは許可された15秒×2回だけ使用し、音声ファイルは0件だった。

## 今回の限界

5分を超える安定性、他の受信機・OS、マイクとドライバーの固定遅延の校正、左右別の音響測定は対象外。
40 msで取得・送信が続くことと、実際に音が鳴ることを区別する。
マイクの追加取得は実施していない。
